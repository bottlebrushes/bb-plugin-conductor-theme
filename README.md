# Conductor Theme for bb

A Conductor-inspired dark and light palette for bb, featuring deep espresso charcoal surfaces, warm brown message cards, bone typography, and emerald green actions.

## Installation

```sh
bb plugin install conductor-theme
```

## Features

- **Geist Typography**: Integrated Geist Sans and Geist Mono typography with standard system fallbacks.
- **Espresso Dark Mode**: Deep `#151110` canvas paired with warm `#2a1e1d` message bubbles and `#3c3635` borders.
- **Emerald & Terracotta Accents**: Emerald green buttons (`#3eb15f`), terracotta symbols (`#d8a599`), and soft cyan branches (`#81ddf9`).
- **Matching Light Palette**: Off-white bone canvas with deep dark roast typography.
